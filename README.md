# Student Management System

## Overview
The Student Management System is a Java-based desktop application developed to simplify the management of student information. It provides an easy-to-use graphical interface for storing, updating, searching, and deleting student records.

## Features
- Add new student records
- Update existing student details
- Delete student records
- Search students by ID or name
- User-friendly Java Swing GUI
- Organized and modular Java code

## Technologies Used
- Java
- Java Swing
- VS Code
- Git & GitHub

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Compile the Java files.
4. Run `StudentManagementGUI.java`.
